# 阿里云部署（函数计算 FC / ECS）

句读是 Next.js 14 App Router 应用：页面 + 4 个 API Route，需要一个能跑 Node 的常驻进程。
阿里云上两条路，按「要不要买服务器」选：

| 方案 | 公网地址 | 成本 | 适合 |
|---|---|---|---|
| **函数计算 FC（推荐）** | `https://xxx.cn-hangzhou.fcapp.run` | 按量，免费额度够演示 | 不想管服务器、要立刻能点开 |
| **ECS / 轻量应用服务器** | `http://公网IP` 或自己的域名 | 包月（学生机/轻量最便宜） | 想要一台固定机器、后面还要跑别的东西 |

两条路都用同一份产物：`sh scripts/pack-standalone.sh` 生成的 `dist-standalone/`。
产物里已经带好 `node_modules`、`.next/static`、`public` 和函数计算要的 `bootstrap`。

---

## 一、函数计算 FC（自定义运行时，不用 Docker）

> **本项目实际已按这套跑通**：`judou-npcgkqkkln.cn-hangzhou.fcapp.run`
> 关键参数见文末「本项目实际参数」。

### 1. 本地打包

```bash
npm ci
sh scripts/pack-standalone.sh
# 产出：dist-standalone/（目录）和 judou-standalone.zip（上传用）
```

### 2. 控制台创建函数

1. 打开 [函数计算控制台](https://fc.console.aliyun.com/) → **函数** → **创建函数**
2. 选择 **Web 函数** → 运行环境选 **Node.js 22（Debian 12）**
   > 别选 Debian 10 的自定义运行时：那个镜像里没有 Node，启动会报 `exec: node: not found`。
3. 基本设置：
   - 函数名称：`judou`
   - 请求处理程序：留空（自定义运行时不需要）
   - **启动命令**：`./bootstrap`
   - **监听端口**：`9000`
4. 代码：**通过 ZIP 包上传** → 选 `judou-standalone.zip`
5. 规格：最小规格即可（0.5 vCPU / 512 MB 够用），超时时间调到 **60 秒**（提炼一次要十几秒）
6. 环境变量：

   | Key | Value |
   |---|---|
   | `OPENAI_API_KEY` | 你的 Key（不填则走公共兜底模型） |
   | `OPENAI_BASE_URL` | `https://api.openai.com/v1`（或任意兼容地址） |
   | `OPENAI_MODEL` | `gpt-4o-mini` |
   | `NEXT_PUBLIC_BUILD_ID` | 任意版本串，例如 `fc-20261127` |

7. 创建后，在函数详情页的 **配置 → 触发器** 里会有一条 HTTP 触发器，公网地址形如
   `https://judou-xxxx.cn-hangzhou.fcapp.run`

### 3. 验证

```bash
URL=https://judou-xxxx.cn-hangzhou.fcapp.run
curl -s $URL/api/health
# {"ok":true,"build":"fc-20261127","model":"public-fallback","version":"1.0.0"}

curl -s -X POST $URL/api/summarize \
  -H 'Content-Type: application/json' \
  -d '{"text":"她最近回消息越来越慢，我是不是哪里做错了？","scene":"flirt"}'
```

`fcapp.run` 是阿里云自己的域名，国内直连，不需要备案、不需要买域名。

> 注意：函数计算会冷启动（第一次请求慢 1–3 秒）；`lib/rateLimit.ts` 是单实例内存限流，
> 多实例时额度会被放大，演示够用。

## 二、ECS / 轻量应用服务器

### 1. 机器

- 系统：Ubuntu 22.04 / Alibaba Cloud Linux 3
- 规格：1 核 2G 起（Next.js 构建建议 2G，否则 `next build` 可能 OOM）
- 安全组：放行 **80**（和 3000，如果不想上 Nginx）

### 2. 装 Node 20

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs nginx
node -v   # v20.x
```

### 3. 上传并构建

在本机打包，然后传上去（把 `1.2.3.4` 换成你的公网 IP）：

```bash
sh scripts/pack-standalone.sh
scp judou-standalone.zip root@1.2.3.4:/tmp/
```

服务器上：

```bash
sudo useradd -r -s /usr/sbin/nologin judou || true
sudo mkdir -p /opt/judou && sudo unzip -q /tmp/judou-standalone.zip -d /opt/judou
sudo chown -R judou:judou /opt/judou

sudo tee /opt/judou/.env >/dev/null <<'EOF'
OPENAI_API_KEY=sk-你的key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
NEXT_PUBLIC_BUILD_ID=ecs-20261127
EOF
sudo chmod 600 /opt/judou/.env
```

### 4. 托管成服务

```bash
sudo cp deploy/judou.service /etc/systemd/system/judou.service
sudo systemctl daemon-reload
sudo systemctl enable --now judou
systemctl status judou --no-pager
curl -s http://127.0.0.1:3000/api/health
```

### 5. Nginx 反代

```bash
sudo cp deploy/nginx.conf /etc/nginx/conf.d/judou.conf
sudo sed -i 's/judou.example.com/你的域名或公网IP/' /etc/nginx/conf.d/judou.conf
sudo nginx -t && sudo systemctl reload nginx
```

直接用公网 IP（`http://1.2.3.4/`）**不需要备案**；一旦绑自己的域名，走阿里云 80/443 必须备案。

### 6. 更新版本

```bash
# 本机
sh scripts/pack-standalone.sh && scp judou-standalone.zip root@1.2.3.4:/tmp/
# 服务器
sudo unzip -oq /tmp/judou-standalone.zip -d /opt/judou && sudo chown -R judou:judou /opt/judou
sudo systemctl restart judou
```

## 三、Docker（可选）

ECS 上装了 Docker 的话更省事：

```bash
docker build -t judou .
docker run -d --name judou --restart=always -p 3000:3000 \
  -e OPENAI_API_KEY=sk-你的key -e OPENAI_BASE_URL=https://api.openai.com/v1 judou
```

## 排错

| 现象 | 处理 |
|---|---|
| FC 返回 502 / 超时 | 启动命令是不是 `./bootstrap`，端口是不是 `9000`；日志里看 `server.js` 有没有起来 |
| 提炼接口 30 秒超时 | 把函数超时时间调到 60–120 秒（公共兜底模型本身慢） |
| `next build` 被 kill | 机器内存不够，加 swap 或换 2G 规格 |
| 页面能开、接口 500 | 环境变量没生效，`curl /api/health` 看 `model` 字段 |
| 桌面小组件连不上 | 小组件只连 `127.0.0.1`，线上部署不影响它 |
